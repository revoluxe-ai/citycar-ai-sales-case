# WB SKY — управление рекламой через ChatGPT

WB SKY — сервис управления рекламой Wildberries, который я разработал и сопровождаю.

В нём реализован такой процесс:

1. Сервис собирает данные магазина и рекламных кампаний.
2. Вместе с данными выгружает текущие управляющие настройки и инструкции.
3. Пакет передаётся в ChatGPT или другой AI-сервис, способный работать с файлами.
4. ИИ анализирует данные и готовит управляющий Excel.
5. Excel импортируется обратно, и сервис использует настройки для управления рекламой через Wildberries API.

В этом процессе файл служит понятным интерфейсом между бизнес-системой и ИИ. На входе у модели есть фактические данные, настройки и инструкции. На выходе получаются конкретные параметры для сервиса.

В моём рабочем сценарии используются модели внутри аккаунта ChatGPT. Оплата запросов к отдельному LLM API для этого потока не нужна; доступ к моделям определяется тарифом и лимитами аккаунта. Формат обмена позволяет использовать разные AI-сервисы, поддерживающие обработку файлов.

Сервис уже работает с платящими клиентами. На собеседовании могу показать реальную выгрузку, анализ, полученный Excel и его загрузку обратно. Данные клиента для демонстрации нужно обезличить.

Стек: Python, SQLAlchemy, PostgreSQL, ClickHouse, Redis, Docker, Kubernetes, Wildberries API, Telegram Bot API.

[Публичный код WB SKY](https://github.com/revoluxe-ai/adv-bot-showcase).
